# 快速创作聊天 Mock · 2026-10-05

独立静态交互原型。无 API、模型请求、GPU 调度、凭据、真实上传或付费调用；文件仅通过浏览器 object URL 本地预览，刷新清空。

演示：新对话→本地素材上传/拖入→选择角色→发送想法→草稿任务卡→编辑/抽卡→开始模拟→结果→下一轮；历史对话独立，旧输入快照保留。多份结果可模拟部分失败后仅重试该份。

模型下拉默认 Gemini 3.8 Flash，可选 Gemma 4 31B IT；这里只变更标签，无智能理解。问号结尾的普通问题进入讨论占位；其它输入形成卡片，正式版由助手判断意图。修改轮次采用文本附加演示，不伪称理解用户要求。

高级项只是布局示例，尚未核对全部 H3 契约；1080p等选项不是当前服务承诺。真实素材组合约束、费用、上限、持久历史、账户权限、Agent同步、全部模型控件及API联调留给设计确认后的实现。

独立预览：用已有 Python 在本目录启动 `python -m http.server 8865 --bind 127.0.0.1`。不要部署或覆盖当前8850页面。

## 第二轮调整
输入框高级控制弹窗设置下一轮，卡片编辑只改该卡。首尾帧和全能参考互斥；切换前确认，素材保留但不兼容项不加入卡片。首帧/尾帧各最多一张。已浏览器验证两张参考图切换首帧时提示另一份保留；高级控制入口与生成方式显示通过。仍为本地 Mock。

## 第三轮：输入限制与频率排序
- 普通参考计数：9图/3视频/3音频，合计12；首尾帧各1。上传、历史重新引用、用途切换、发送和任务启动校验共用 limits.js。
- 音视频读取浏览器本地时长；2–15秒选段，同类累计15秒。无效时长阻止发送；可打开片段弹窗修正。源文件超过1小时拒绝；此处不裁文件、不上传服务器。
- 高级选项顺序：常用输出项→参考与时间→随机性与采样→音画日程→运行与导出，低频默认折叠。排序为设计假设，后续按使用反馈调整。
- 移除无实际映射的负面词/CFG；使用480P/576P/768P，支持4–15秒、完整采样器和调度器枚举、sigma shift、解码分块、编码器、CRF。
- 9个离线输入边界断言通过；浏览器验证第10张图拒绝、16秒音频禁止发送、修改为8秒片段成功、高级分组折叠。
- 仍未完成：结构化时间锚点、自定义宽高、每视频原声开关、后端实际解码与尺寸校验、媒体标准化后时长校验、真实执行池能力/费用、真实API。所有本轮数据仅标签页内存，不宣称正式功能完成。
