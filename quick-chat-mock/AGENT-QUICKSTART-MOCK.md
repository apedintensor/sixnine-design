# 映序 Agent 接入 · 交互设计稿

状态：MOCK，仅供审阅。DEMO_NOT_VALID_ 开头的值不能认证。本文件不授权任何真实调用、上传、GPU租赁或生成。

## 用户想完成什么
用户把网站接入文档交给 Codex，在本地安全配置自己的网站 API Key，然后用自然语言创作。Agent 与网页共享同一份故事、对话、素材、任务和结果。Key 不是 Google 或 GPU 供应商的密钥。

## 接入约定
1. 正式实现先读目标站点的官方 Skill/OpenAPI/能力接口，确认版本、认证方式和当前范围；不要从此 mock 猜测接口。
2. API Key 通过用户本地密钥管理器提供，只在请求内使用，不写入提示词、日志、URL或公共文档。
3. 默认完整创作权限覆盖用户有权访问的故事、章节、角色、场景、素材、对话与任务；账户隔离仍有效，不能越权管理其他用户、密钥、基础设施或预算。
4. 用户只是讨论时保存草稿任务卡；用户明确授权生成时，才预检并提交。素材上限、互斥、预算与当前执行池约束必须先检查。不能为了过检偷偷改参数或换模型。
5. 提交用幂等机制；网络结果未知先对账，不能重复付费生成。抽卡作为同一批多份结果，各自记录种子与状态。
6. 把项目/会话/任务标识及网页链接返回用户。后续读取原上下文，修改产生新版本，不能覆盖已提交快照。
7. 撤销 Key 停止后续访问，不自动取消已接收任务。

## 现有实现与目标的区别
现有项目已有 Agent 文档和项目/镜头生成 API，详见 h3-studio/AGENT-ONBOARDING.zh-CN.md、FREESTYLE-AGENT.zh-CN.md 及项目内 Skill。新的聊天会话/任务卡契约仍待设计确认，不声称已有完整支持。此 mock 不接现有生产认证，也不签发 PAT。

本地入口 http://127.0.0.1:8865/ 仅这台电脑可访问；远程 Agent 应接收本文件。正式版会提供公开 HTTPS 文档入口，文档本身不包含任何私有凭据。

## Key 的具体配置位置
现有网站 Skill 客户端读取进程环境变量 SIXNINE_API_KEY；正式源站 https://www.sixnine.art。不是 Codex 的模型 Key。配置指南见同目录 agent-setup.html。桌面应用复用用户选定的本地加密库；CLI 可在 PowerShell 用 Read-Host -AsSecureString 输入后通过进程环境传给同一终端启动的 codex。不要把真实值贴进聊天、文档、命令参数或项目.env。已运行的桌面应用不会自动继承另一个终端的新变量。
用户机器如已有中央 Registry，核对 sixnine profile 的账户和端点后复用；无匹配时由本地安全输入流程配置，不擅自选首个账户。配置不等于鉴权成功，需独立只读验证；本原型不执行真实验证。
