用户只需要做三件事

  1. 为自己的 Agent 创建网站 API Key。
  2. 在本地密钥管理器安全配置，不把真实 Key 贴到对话里。
  3. 把这份文档和创作目标交给 Codex。

Key 放在哪里？怎么设置？

密钥变量名是 SIXNINE_API_KEY，正式服务地址是 https://www.sixnine.art。这是网站客户端凭据，不是 Codex 的模型供应商 Key。

Agent 可做什么

读取并编辑用户可访问的故事、章节、角色、场景、素材和创作对话；根据明确授权提交任务、查看状态、下载和采用结果。所有操作应回到网页同一份数据。

正式连接时先读真实契约

接口地址、字段、身份验证、能力上限和幂等规则以站点实际发布的 Skill / OpenAPI 为准。新的聊天任务卡接口还未实现，本页不提供编造的可执行调用示例。

Key 不包含跨账户权限、密钥管理、基础设施或预算管理。撤销后禁止新访问，已有任务不自动取消。
