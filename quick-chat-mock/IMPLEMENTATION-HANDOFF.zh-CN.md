- 进入快速创作直接上传本地图片/视频/音频并输入需求，不要求先创建故事、章节、导入旧任务或选画布。

- 同一会话材料/参数延续；本轮实际使用哪些材料可见且可移除，删除引用不删除历史原件；不同会话隔离。

- 卡片支持多份抽卡，独立种子/状态/输出，部分失败保留成功结果、仅重试失败项；未知提交先对账，不双投。
- 输入区高级控制按钮打开弹窗设置下一轮；卡片单独编辑只作用该卡。先常用方式/时长/分辨率/画幅/份数/声音，再参考与时间、随机采样、音画日程、运行导出，低频折叠。
- API Key 与 Agent 入口固定侧栏底部、账户区上方。
- Agent 可通过网站API进行完整创作、读取可访问内容；网页与Agent共用数据，不是独立文件输出。默认广泛创作权限，保留账户边界/预算/基础设施权限边界。
